# KU Design Competitions and Events

A board of student design competitions, design conferences and portfolio events for University of Kansas design students (VISC, IXD, illustration, animation, industrial design). Maintained by Titus Smith.

- `index.html` is the whole board: one self-contained page. Open it in a browser, or view it on GitHub Pages if it's turned on for this repo.
- The working copy (with the instructor's Suggested tab and editing) lives on claude.ai; this repo is a read-only snapshot for sharing. Snapshots are updated as the board changes.

Feedback: open an issue or email Titus.
